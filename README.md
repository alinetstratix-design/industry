# ATHETEC TECHNOLOGIES - Industrial & Engineering MSME Landing Page

High-conversion B2B corporate landing page and product machinery catalog clone demo inspired by Bhavani Engineering, tailored for **ATHETEC TECHNOLOGIES** (Haridwar, Uttarakhand).

## 🚀 Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Vanilla CSS with modern responsive design system
- **Icons**: Lucide React

## 📋 Features
- Top Bar with direct call (`+91 8126287325`), MSME badges, IndiaMART and JustDial links
- Dynamic Industrial Hero Banner with slide switcher and signature floating contact bar
- 15+ Years Stats Counter Section
- Comprehensive About Section with industrial story & credentials
- 8 Core Industrial Services with interactive technical specification modals:
  - Process Piping (SS / MS)
  - Utility Piping Systems
  - IBR High Pressure Steam Piping
  - Fire Hydrant & Industrial Safety Networks
  - Heavy Structural Fabrication & PEB
  - Machine Installation & Commissioning
  - Storage Tanks, Reaction Vessels & Conveyors
  - Cleanroom Pharma Equipment & Process Utensils
- Machinery & Product Catalog with category filter tabs and WhatsApp RFQ integration
- Why Choose Us & Competencies Ribbon
- Prestige Projects & Client Portfolio (Carlsberg, ITC, HUL, Amcor, Amazon)
- Interactive Request for Quotation (RFQ) Form
- Google Business Location Map & Route Directions (Shivalik Nagar, Haridwar)
- Floating Quick Connect (Call + WhatsApp)

## 🛠️ Getting Started
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Run production build
npm run build
npm start
```
